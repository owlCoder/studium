# Predlog razvojnog toka prema temama ERS

Ovaj plan povezuje nastavu i projekat. Nije raspored rokova niti pravilo ocenjivanja; redosled i zaduženja tim dogovara prema odabranim STUDIUM zahtevima.

| Tema | Tipičan izlaz u repozitorijumu |
| --- | --- |
| Zahtevi, backlog i Git | Jedna jasna korisnička priča, kriterijumi, issue, mala grana i PR |
| SOLID i čista arhitektura | Granice modula i obrazložen ADR |
| Domena i slučajevi upotrebe | Entitet, invarijante, portovi i slučaj upotrebe |
| Testabilnost, NUnit i Moq | Testovi pozitivnih i negativnih ishoda |
| Integracija modula | Jasni ugovori, adapter i integracioni test |
| Kontrolisan razvoj uz AI | Dokumentovan pregled predloga, potvrđene komande i ograničenja |
| MCP i razvojni alati | Mali, ograničeni alat koji ne zaobilazi prava pristupa |
| Guardrails, evaluacije i kvalitet | Proverljivi ishodi, retrospektiva i dokaz stabilne integracije |

Pre zatvaranja zadatka član tima treba da pokaže: **zahtev → odluku → implementaciju → test → PR → prihvaćen rezultat**.

Navedene teme predstavljaju nastavne orijentire; ne postoji zahtev da se svaki alat ili primer iz praktikuma obavezno ugradi u STUDIUM sistem.
